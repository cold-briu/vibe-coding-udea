Local AI

Guía práctica profesional para montar tu agente de IA local resiliente usando Ollama, LM Studio, OpenCode y Hermes.

2. Ollama — Modelos locales ultra-rápidos

Ollama empaqueta y corre LLMs locales bajo un motor minimalista y potente basado en llama.cpp. Permite descargar, instanciar y consultar modelos vía terminal o API en minutos.

# Instalar en macOS
brew install ollama

# Instalar en Linux
curl -fsSL https://ollama.com/install.sh | sh

# Instalar en Windows
# Descarga e instala directamente el instalador oficial desde ollama.com/download

Qué modelo elegir según tu VRAM / RAM

Ollama corre bajo cuantizaciones estándar. Elige el tamaño del modelo basándote estrictamente en tu memoria disponible para evitar desbordamientos al disco (Swap) que destrozan la velocidad de inferencia:

RAM / VRAM Modelo recomendado Tamaño Propósito Principal
8 GB llama3.2:1b, qwen2.5:1.5b o gemma4:e2b ~1.0 - 7.2 GB Baja latencia, edge, texto+imagen+audio
16 GB llama3.1:8b, qwen2.5-coder:7b o gemma4:12b ~4.7 - 7.6 GB Uso general, programación, multimodal (256K ctx)
24 GB qwen2.5-coder:14b o gemma4:26b (MoE Q4) ~9.0 - 18 GB Sweet spot calidad/velocidad, 4B activos de 26B
32 GB gemma4:31b (Q4) o gemma4:26b (Q8) ~18 - 20 GB Calidad densa 31B, 256K contexto nativo
48 GB+ llama3:70b (Q4), mixtral:8x7b o gemma4:31b (BF16) ~40 - 70 GB Calidad premium comparable a servicios cloud comerciales

Gemma 4 E2B/E4B tienen 128K de contexto nativo; 12B/26B/31B tienen 256K. Todos con licencia Apache 2.0. ollama.com/library/gemma4

# Descargar y levantar un modelo en modo interactivo
ollama run qwen2.5-coder:7b

# Monitorear modelos en memoria activos
ollama ps

# Servidor API por defecto en http://localhost:11434
ollama serve
IMPORTANTE Configuración del Context Window (num_ctx)

Ollama usa por defecto 2048 tokens de contexto, pero desde la versión 0.6+ ajusta automáticamente según VRAM (<24 GB = 4K, 24-48 GB = 32K, ≥48 GB = 256K). Para agentes como OpenCode y Hermes necesitas al menos 64K tokens. El contexto se configura mediante num_ctx — si el valor excede el límite del modelo, se trunca automáticamente al máximo soportado.

Opción 1: Variable de entorno global (para todos los modelos)

# Arrancar el servidor con contexto de 64K tokens
OLLAMA_CONTEXT_LENGTH=64000 ollama serve

# En macOS (permanente vía LaunchAgents), agrega al plist:
# <key>EnvironmentVariables</key><dict>
#   <key>OLLAMA_CONTEXT_LENGTH</key><string>64000</string>
# </dict>

# En Linux (permanente con systemd):
# sudo systemctl edit ollama.service
# [Service]
# Environment="OLLAMA_CONTEXT_LENGTH=64000"
# sudo systemctl daemon-reload && sudo systemctl restart ollama

Opción 2: Por modelo vía Modelfile (recomendado)

# Crear un Modelfile con contexto persistente para el modelo
cat > Modelfile << 'EOF'
FROM qwen2.5-coder:7b
PARAMETER num_ctx 65536
EOF

# Construir el nuevo modelo con el contexto fijado
ollama create qwen2.5-coder:7b-64k -f Modelfile

# Usar el nuevo modelo
ollama run qwen2.5-coder:7b-64k

Opción 3: Por solicitud API (por llamada)

curl http://localhost:11434/api/generate -d '{
  "model": "qwen2.5-coder:7b",
  "prompt": "Tu prompt largo aquí...",
  "options": {
    "num_ctx": 65536
  }
}'

Opción 4: Interactivo (sesión temporal)

ollama run qwen2.5-coder:7b
# Dentro de la sesión:
/set parameter num_ctx 65536

Concurrencia y modelos paralelos

# Variables de entorno adicionales para concurrencia:
OLLAMA_NUM_PARALLEL=4     # Solicitudes paralelas por modelo (default: 1)
OLLAMA_MAX_LOADED_MODELS=2 # Modelos simultáneos en memoria

# macOS (LaunchAgents):
# <key>OLLAMA_NUM_PARALLEL</key><string>4</string>
# <key>OLLAMA_MAX_LOADED_MODELS</key><string>2</string>

# Linux (systemd):
# Environment="OLLAMA_NUM_PARALLEL=4"
# Environment="OLLAMA_MAX_LOADED_MODELS=2"

3. LM Studio — Interfaz robusta para GGUF

LM Studio proporciona una interfaz gráfica potente y modular para descargar, probar y configurar archivos en formato GGUF procedentes de Hugging Face de forma visual y directa.

  1. Descarga el instalador nativo según tu plataforma en lmstudio.ai.
  2. Navega a la pestaña de Búsqueda para encontrar repositorios públicos en segundos (ej: llama-3.1-8b-instruct, qwen2.5-coder-7b).
  3. Descarga la cuantización GGUF que se ajuste a tu VRAM (recomendado Q4_K_M o Q5_K_M).
  4. Navega al servidor local en la barra lateral izquierda, asocia el modelo descargado y haz clic en Start Server.
  5. Esto iniciará una API compatible con OpenAI en http://localhost:1234/v1.
TIP DE POWERUSER Uso de LM Studio por CLI (`lms`)

LM Studio incluye un binario de terminal llamado lms. Úsalo para automatizar el ciclo de arrancar el servidor y cargar modelos programáticamente:

# Instalar las herramientas CLI de LM Studio en el PATH
# Ejecutar en la app del sistema o usar este wrapper:
lms bootstrap

# Arrancar el servidor compatible con OpenAI vía terminal
lms server start --port 1234

# Cargar un modelo GGUF descargado directamente en memoria
lms load "lmstudio-community/qwen2.5-coder-7b-instruct-GGUF" --context-length 64000

# Ver qué modelos están listos para inferencia
lms status

4. OpenCode — El agente de código provider-agnóstico

OpenCode es un agente de codificación open-source y modular que opera directamente sobre la terminal (TUI) y se acopla a cualquier pasarela local o API externa compatible con OpenAI.

Instalación global

# Instalación limpia vía Node Package Manager (NPM)
npm install -g @opencode-ai/cli

Configurar para trabajar con Ollama

Inicia el agente apuntando directamente al puerto local donde Ollama corre sus servicios:

opencode --provider ollama --model qwen2.5-coder:7b

Configurar para trabajar con LM Studio

Apunta el agente a la API compatible levantada por LM Studio:

opencode --provider openai --base-url http://localhost:1234/v1 --model qwen2.5-coder-7b-instruct

5. Hermes Agent — El runtime autónomo que se automejora

Hermes Agent es un runtime de IA autónomo (patrocinado por Nous Research) con licencia MIT. No es un simple copiloto o envoltorio de chat: se trata de un núcleo persistente con memoria SQLite + FTS5 nativa, arquitectura cron incorporada y creación automática de habilidades.

¿Qué marca la diferencia en Hermes?
  • Persistencia de Memoria: No empieza de cero cada vez. Utiliza bases de datos SQLite + FTS5 y embeddings locales/remotos para almacenar, refinar y recordar las preferencias operativas del usuario y el historial inter-sesión.
  • Auto-generación de Skills: Cuando solventa una tarea compleja o de múltiples pasos (5+ tool calls), genera un script estructurado en ~/.hermes/skills/. El subsistema Curador re-evalúa y limpia estas habilidades recursivamente.
  • Gateway Multicanal: Un único daemon levanta una red multi-plataforma que conecta a tu agente local con Telegram, Discord, Slack, WhatsApp u otras 15+ pasarelas simultáneamente de forma transparente.
  • Gestión de Subagentes: Permite delegación nativa y concurrente (delegate_task) lanzando múltiples subprocesos aislados para depurar o investigar en paralelo.

Instalación estructurada

# Descarga e instalador automatizado para macOS y Linux
curl -fsSL https://hermes-agent.org/install.sh | sh

# En entornos aislados de Python (macOS) - usando pip o uv
python3 -m venv ~/.hermes/venv
source ~/.hermes/venv/bin/activate
pip install -U hermes-agent

# Asistente guiado de configuración inicial
hermes setup

# Inicializar y depurar salud del sistema
hermes doctor
NATIVO Configuración Local de `~/.hermes/config.yaml`

Para asegurar que Hermes conecte adecuadamente con tu motor local sin exigir recursos cloud o fallar revisiones de la API, edita tu archivo de configuración especificando la URL del servicio local:

# Conexión local a Ollama en ~/.hermes/config.yaml
model:
  default: qwen2.5-coder:14b  # Reemplazar con tu modelo descargado
  context_length: 64000       # Indicar el contexto explícitamente
  base_url: http://localhost:11434/v1
  provider: openai            # Usar envoltorio estándar OpenAI

# O LM Studio de forma predeterminada:
# model:
#   default: qwen2.5-coder-7b-instruct
#   context_length: 64000
#   base_url: http://localhost:1234/v1
#   provider: openai

6. Cómo operar OpenCode de forma Headless

OpenCode brilla en su interfaz de terminal integrada (TUI), pero además soporta automatizaciones a bajo nivel en segundo plano útiles para pipelines de integración continua o llamadas asíncronas.

Ejecución headless para refactorización de lógica

# Ejecutar comandos directamente sin ingresar a la interfaz interactiva
opencode run -p "Parce, refactoriza este index.js para que use async/await limpios" \
  --provider ollama --model qwen2.5-coder:7b

# Auditoría de seguridad local
opencode run -p "Haz una auditoría de dependencias y vulnerabilidades en package.json" \
  --provider openai --base-url http://localhost:11434/v1 --model llama3.1:8b

8. El Gateway de Hermes — Tu agente en todas partes

El modulo Gateway es un puente de comunicación unificado que de forma reactiva asocia cualquier sistema de chat con el runtime local. Esto permite interactuar con el mismo agente que corre en la GPU del ordenador directamente desde tu teléfono móvil.

Plataforma Propósito Típico Beneficio Destacado
Terminal (CLI) Gestión de sistemas, codificación ágil Acceso directo al kernel y shell del sistema
Telegram Control móvil, consultas rápidas Soporta notas de voz transcritas con Whisper local
Slack / Discord Canal corporativo y de comunidades Permite resolver bugs en equipo in-situ
WhatsApp / Signal Acceso seguro libre de apps adicionales Ecosistema de alta confidencialidad
Email (SMTP) Reportería asíncrona avanzada Despacha PDFs e informes elaborados de forma autónoma 
# Configurar tus credenciales de mensajería (Telegram, Slack, etc.)
hermes gateway setup

# Poner en marcha el Gateway en segundo plano
hermes gateway run

Correr 24/7 sin gastar — Oracle Free Tier o VPS barato

El gateway de Hermes es liviano y corre sin GPU. Puedes dejarlo corriendo 24/7 completamente gratis en la capa gratuita de Oracle Cloud (VM.Standard.ARM.A1 — 4 OCPUs, 24 GB RAM) o en cualquier VPS de ~$5/mes (Hetzner, Netcup, RackNerd). El agente pesado (LLM) corre en tu máquina local con GPU; el gateway en la VPS recibe los mensajes de Telegram/WhatsApp y se comunica con tu agente local via API.

# 1. Instalar Hermes en la VPS
curl -fsSL https://hermes-agent.org/install.sh | sh

# 2. Configurar solo el gateway (sin modelo local)
hermes gateway setup   # Telegram, WhatsApp, etc.

# 3. Iniciar el gateway
hermes gateway run

# 4. (Opcional) Como servicio systemd para que arranque solo
sudo tee /etc/systemd/system/hermes-gateway.service <<EOF
[Unit]
Description=Hermes Gateway
After=network.target

[Service]
Type=simple
User=tu-usuario
ExecStart=$(which hermes) gateway run
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now hermes-gateway

Oracle Free Tier: oracle.com/cloud/free — VM.ARM.A1 siempre gratis (4 cores, 24GB).
Alternativas baratas: Hetzner (hetzner.com) desde ~3.5€/mes, Netcup desde ~2€/mes.

9. Credential Pools — Rotación inteligente de Claves

Cuando un flujo local requiere alternar con pasarelas comerciales (OpenRouter, Anthropic o OpenAI), Hermes previene caídas de servicio por expiración de cuota o límites de concurrencia mediante un pool inteligente de rotación.

Estrategias de Rotación del Pool

Puedes configurar el orden y la lógica de transición según tu volumen de desarrollo:

  • fill_first: Exprime la primera clave registrada hasta saturarla antes de saltar a la siguiente.
  • round_robin: Distribución balanceada alternando equitativamente en cada token.
  • least_used: Prioriza las llaves con menor consumo histórico.
# Listar claves asociadas y cooldowns activos
hermes auth list

# Agregar una clave secundaria para OpenRouter
hermes auth add openrouter --api-key sk-or-...-your-key-2

# Reiniciar y limpiar bloqueos transitorios en el pool
hermes auth reset openrouter

10. Automatización Extrema con Cron e Inteligencia en Local

La combinación de un programador interno con un modelo local erradica las cuotas operativas. Puedes planificar tareas concurrentes que examinen bases de datos, mantengan repositorios o alerten sobre logs de forma perpetua.

# Programar tareas rutinarias en lenguaje natural
hermes cron add "Cada 30 minutos revisa estado del repo /paletas y si hay cambios sin commit, haz pull nocturno"

# Buscar noticias técnicas con tu modelo local sin costo de Tokens
hermes cron add "Cada mañana a las 7 AM escrapea novedades sobre LLMs, haz un resumen y envíalo por Telegram"

# Listar las tareas de automatización activas
hermes cron list
