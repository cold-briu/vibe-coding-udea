# La Alquimia — Local AI

Este proyecto contiene una guía práctica y profesional para configurar y optimizar agentes de Inteligencia Artificial locales e interactivos utilizando soluciones *open-source*.

---

## 🛠️ Contenido de la Guía
1. **La Terminal (CLI):** Comandos esenciales multiplataforma.
2. **Ollama:** Motores locales eficientes, dimensionamiento según gráficos/RAM y ajuste de contextos dinámicos (`OLLAMA_NUM_PARALLEL`, systemd, plist).
3. **LM Studio:** Guía visual de modelos GGUF y orquestación desatendida mediante su binario de consola `lms`.
4. **OpenCode:** Integración de un agente autónomo headless para pipelines de desarrollo.
5. **Hermes Agent:** Runtime autónomo multiplataforma, daemon de persistencia, cron nativos y autogeneración de habilidades.
6. **Credential Pools:** Lógicas avanzadas de rotación de claves API integradas.
